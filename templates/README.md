# Q-Ontic templates

This directory is the canonical starting point for new Q-Ontic interactive material.

- [`qontic-app/`](./qontic-app/) — simulation-style apps with a primary canvas or interactive stage.
- [`qontic-notebook/`](./qontic-notebook/) — guided multi-section notebooks with the same header, footer and themes.

Runtime-wide brand assets live in [`../shared/`](../shared/). Templates consume those assets; individual apps should not duplicate them.
