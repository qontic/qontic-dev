Physics and model limits

The cloud shows total spinor density and the dots trace pilot-wave trajectories. The default packet starts in an equal, in-phase superposition of +z and −z spin. With the gradient enabled, the two components tend to separate vertically.

Wave

The wave function is a two-component spinor. Its density is

ρ(x,t) = Ψ†Ψ

The Pauli spinor evolves on a grid with periodic boundaries along x and hard walls along y and z. Compare the early motion before reflections become important. The model uses a magnetic field across the simulation region and a detector plate that stops trajectories on contact while the wave keeps evolving.

Guidance

The Bohmian velocity is the sum of the convective current and the spin current divided by density. The convective current is

vB = jconvρ
jconv = ℏm Im (Ψ†∇Ψ)

The spin-current coefficient s is ½ for the Pauli current. Varying it changes the guidance law while the wave evolves with the same Pauli equation. The controls use simulation units.

v = jconvρ + sℏ mρ ∇× (Ψ†σΨ)
